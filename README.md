## 📖 Giới thiệu (Overview)

**ExamPrep Studio** là ứng dụng desktop toàn diện được thiết kế chuyên biệt cho học sinh, sinh viên và giáo viên nhằm tối ưu hóa quá trình ôn thi trắc nghiệm, quản lý ngân hàng đề thi và theo dõi tiến độ học tập một cách khoa học.

Ứng dụng hoạt động theo cơ chế **Offline-First**, lưu trữ dữ liệu cục bộ an toàn, hỗ trợ hiển thị công thức Toán học & Khoa học (LaTeX/KaTeX), tích hợp công nghệ ghi nhớ Flashcard (Spaced Repetition) và hệ thống phân tích năng lực học tập trực quan.

## ✨ Tính năng nổi bật (Key Features)

### 1. 🎯 Ngân hàng Câu hỏi & Quản lý Môn học
- **Phân loại khoa học**: Tổ chức câu hỏi theo Môn học, Chuyên đề, Mức độ nhận thức (*Nhận biết, Thông hiểu, Vận dụng, Vận dụng cao*).
- **Bộ lọc & Tìm kiếm nhanh**: Tìm kiếm theo từ khóa, lọc theo độ khó, gắn tag chuyên đề.
- **Trình soạn thảo phong phú**: Hỗ trợ định dạng văn bản, chèn hình ảnh, bảng biểu và công thức toán học KaTeX.

### 2. 📥 Nhập đề thông minh đa định dạng (Smart Importer)
- Nhập nhanh ngân hàng câu hỏi từ các file: **Word (.docx)**, **Excel (.xlsx)**, **PDF**, **CSV**, **JSON**.
- Parser thông minh tự động nhận diện câu hỏi, các phương án lựa chọn (A, B, C, D), đáp án đúng và lời giải chi tiết.

### 3. 🧪 Chế độ Thi & Luyện tập đa dạng
- **Chế độ Thi thử (Exam Mode)**: Bấm giờ nghiêm ngặt, trộn thứ tự câu hỏi và đáp án ngẫu nhiên, mô phỏng kỳ thi thực tế.
- **Chế độ Luyện tập (Practice Mode)**: Xem ngay giải thích chi tiết sau mỗi câu, hỗ trợ củng cố kiến thức tức thì.
- **Ôn tập câu sai & Đánh dấu (Review Marked / Mistakes)**: Tự động tổng hợp các câu làm sai hoặc câu được gắn cờ để luyện lại đến khi thuần thục.

### 4. 🗂️ Flashcard & Lặp lại ngắt quãng (Spaced Repetition)
- Tạo và ôn tập bộ thẻ ghi nhớ từ vựng, công thức, định lý nhanh chóng.
- Ứng dụng thuật toán lặp lại ngắt quãng giúp tối ưu hóa khả năng ghi nhớ dài hạn.

### 5. 📊 Thống kê & Phân tích năng lực chuyên sâu (Analytics)
- Biểu đồ điểm số, thời gian làm bài trung bình, tỷ lệ độ chính xác theo từng chuyên đề (Recharts).
- Tự động nhận diện điểm mạnh, điểm yếu và gợi ý nội dung cần tập trung ôn tập.

### 6. 🔄 Tự động cập nhật (Auto-Updater)
- Tích hợp tự động kiểm tra và nâng cấp phiên bản mới mượt mà qua GitHub Releases.
- Bảo toàn 100% dữ liệu học tập và ngân hàng câu hỏi khi nâng cấp.

## 🚀 Hướng dẫn Cài đặt & Phát triển (Getting Started)

### Yêu cầu môi trường (Prerequisites)
- [Node.js](https://nodejs.org/) `>= 20.x`
- Trình quản lý gói `npm`
- Hệ điều hành: Windows 10/11 (64-bit)

### 1. Clone mã nguồn
```bash
git clone https://github.com/thinh8802/ExampStudio.git
cd ExampStudio/quiz_app
```

### 2. Cài đặt Dependencies
```bash
npm install
```

### 3. Khởi chạy môi trường phát triển (Dev Mode)
Chạy trên trình duyệt:
```bash
npm run dev
```

Khởi chạy cùng Electron Desktop:
```bash
npm run dev
# Mở một terminal mới:
npx electron .
```

## 📦 Đóng gói ứng dụng (Build & Packaging)

### Tạo bộ cài đặt Windows (.exe Setup)
```bash
npm run build:exe
```
File cài đặt hoàn chỉnh (`ExamPrepStudio-Setup-<phiên-bản>.exe`) sẽ được tạo trong thư mục `release/`.

## 📂 Cấu trúc Thư mục (Project Structure)

```text
quiz_app/
├── .github/workflows/    # CI/CD GitHub Actions phát hành tự động
├── electron/             # Mã nguồn Main Process Electron (main.cjs, preload)
├── build/                # Tài nguyên Icon, NSIS script cấu hình bộ cài
├── scripts/              # Script hỗ trợ build & phân loại gói cài đặt
├── src/
│   ├── assets/           # Hình ảnh, âm thanh, icon tĩnh
│   ├── components/       # Các UI Component dùng chung
│   ├── db/               # Dexie IndexedDB Schema & Repositories
│   ├── pages/            # Các màn hình chính (Dashboard, Exam, Import...)
│   ├── services/         # Update Service, Parser Services, Storage
│   ├── stores/           # Zustand State Management
│   ├── types/            # TypeScript Type Definitions
│   └── utils/            # Helper functions, KaTeX parser, Formatters
└── README.md
```
